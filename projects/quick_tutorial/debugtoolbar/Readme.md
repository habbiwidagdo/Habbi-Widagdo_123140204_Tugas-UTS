Analysis
Pada tahap ini saya mempelajari bagaimana cara menambahkan pyramid_debugtoolbar sebagai add-on untuk mempermudah proses debugging selama pengembangan.
1. pyramid_debugtoolbar adalah paket Python biasa
2. Add-on Pyramid perlu di-include ke aplikasi
3. Toolbar ini muncul otomatis di browser
4. Debugtoolbar menyisipkan HTML/CSS ke dalam aplikasi
5. Belajar tentang Setuptools extras

Extra Credit 
- Karena debugtoolbar hanya digunakan saat pengembangan (development), bukan saat aplikasi dijalankan di production.
- Supaya aplikasi menghasilkan error. Ketika saya membuka browser lagi, debugtoolbar otomatis menampilkan traceback lengkap.
