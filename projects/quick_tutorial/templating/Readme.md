Analysis
Pada langkah ini, saya belajar bagaimana Pyramid menangani HTML menggunakan template, bukan lagi memasukkan HTML langsung ke dalam kode Python. Cara sebelumnya memang bisa, tapi tidak praktis dan sulit dirawat jika aplikasinya makin besar. Pyramid sendiri tidak mengunci developer pada satu templating engine. Untuk latihan ini, saya memakai pyramid_chameleon, karena dokumentasinya ringan dan integrasinya mulus.

Saya juga perhatikan bahwa kedua view (home dan hello) bisa memakai template yang sama, hanya datanya yang berbeda. Ini membuat template jadi lebih reusable dan modular. Untuk pengembangan, menambahkan pyramid.reload_templates = true di development.ini sangat membantu, karena setiap perubahan template langsung terlihat tanpa restart server. Di bagian testing, pola pengujian juga berubah. Karena view sekarang mengembalikan dictionary, saya bisa mengetes datanya langsung tanpa harus mem-parsing HTML. Baru di functional test saya memastikan bahwa HTML yang di-render memang berisi teks yang sesuai.
